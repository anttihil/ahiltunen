UCLA Web Platform & Automated Migration

Helped redesign UCLA’s fragmented collection of departmental and project websites into a centrally managed AWS platform with reproducible infrastructure and deployments. I conceived and built an automated migration system that used coding agents to analyze massive, inconsistent XML exports and turn what they discovered into deterministic transformation rules. The modular pipeline preserved site structure and content while avoiding an estimated 1,000 hours of manual migration work, with about 15 sites onboarded before I left.
